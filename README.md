# Work & Brew ☕📍

Work & Brew is a mobile application designed to help remote workers and creatives discover
vetted, work-friendly cafés with reliable WiFi, seating, and focus-friendly atmospheres.

## 🚧 Status
In active development (MVP phase)

## ✨ Core Features (MVP)
- Discover work-friendly cafés by location
- Café of the Week spotlight
- Save and favorite cafés
- Focus tools to support productive sessions

## 🛠 Tech Stack
- React Native (Expo)
- JavaScript
- Expo Router
- GitHub for version control

## 🎯 Vision
Work & Brew aims to bridge productivity and local cafes by making it easier to find spaces
that support deep work and creativity, starting in NYC.
